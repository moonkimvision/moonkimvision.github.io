골인

말을 칸에 놓으면 자동으로 자리를 잡아요. 같은 편 말은 업히고, 상대 말이 있는 칸에 놓으면 잡아서 대기 줄로 돌려보내요. 도착한 칸에 도·개·걸·윷·모가 표시되고, 한 칸 뒤로 옮기면 빽도로 알려줘요. 들어온 말은 이 칸으로 끌어다 놓으세요.

기록판

    TV·빔에 띄우고 다 같이 하는 법

    누나TV에 판 크게 띄워 놓고 하면 진짜 명절 느낌 나. 아 잠깐, 리모컨 어디 갔지?

    동생…휴대폰으로 하면 돼.

    누나갤럭시면 스마트뷰. 손가락 두 번이면 끝이야. 진짜로. 아 잠깐, 세 번인가.

    동생…와이파이 먼저.

    1. 휴대폰과 TV를 같은 와이파이에 연결해요.
    2. 휴대폰 화면 맨 위에서 아래로 두 번 쓸어내려 빠른 설정을 열고 Smart View를 눌러요. 안 보이면 빠른 설정의 연필(편집) 버튼에서 추가할 수 있어요.
    3. 목록에서 우리 집 TV를 고르고, TV에 허용 창이 뜨면 리모컨으로 허용을 눌러요. (처음 한 번만 물어봐요)
    4. 휴대폰을 가로로 돌린 뒤 이 화면 위의 전체화면을 누르면 TV에 판이 꽉 차요.
    5. 말은 휴대폰에서 손가락으로 끌어 놓아요. 소리는 보통 TV 스피커로 나와요.

    LG·다른 회사 TV도 화면 공유(미라캐스트)를 지원하면 Smart View 목록에 떠요. TV가 안 보이면 TV를 껐다 켜고, 휴대폰 와이파이를 한 번 다시 연결해 보세요.

    누나아이폰은 화면 미러링이야. 근데 TV가 에어플레이를 알아야 해. 우리 집 TV는… 아 잠깐, 모르겠다.

    동생…TV 설정에 있어.

    1. 아이폰과 TV(또는 Apple TV)를 같은 와이파이에 연결해요. TV 설정에서 AirPlay가 켜져 있어야 해요.
    2. 화면 오른쪽 위에서 아래로 쓸어내려 제어 센터를 열고 화면 미러링(겹친 네모 두 개)을 눌러요.
    3. TV를 고르고, TV에 뜬 숫자 코드를 아이폰에 입력해요.
    4. 제어 센터에서 세로 화면 고정을 끄고 아이폰을 가로로 돌려요.
    5. 아이폰은 브라우저에서 전체화면이 안 돼요. 공유 버튼 → 홈 화면에 추가로 아이콘을 만들고, 그 아이콘으로 열면 주소창 없이 꽉 차요.

    AirPlay가 없는 TV는 라이트닝(또는 USB-C) → HDMI 어댑터로 선을 연결하면 바로 나와요.

    누나빔 쏘면 벽 전체가 윷판이야. 영화관 같지? 아 잠깐, 불은 다 끄지 마. 윷 안 보여.

    동생…커튼만.

    1. 노트북을 HDMI 선으로 빔프로젝터(또는 TV)에 연결해요. 휴대폰은 USB-C → HDMI 어댑터가 있으면 같은 방법으로 돼요.
    2. 윈도우는 Win + P → 복제, 맥은 디스플레이 설정에서 미러링을 골라요.
    3. 브라우저에서 이 게임을 열고 키보드 F(또는 위의 전체화면)를 눌러요.
    4. 말은 마우스로 끌어 놓아요. 무선 마우스 하나를 돌려 가며 쓰면 자리에서 일어날 필요가 없어요.
    5. 빔에 무선 미러링(스크린 미러링·미라캐스트)이 있으면 휴대폰 스마트뷰로 선 없이 연결돼요.

    밝은 방이면 커튼을 치고, 판이 작아 보이면 빔을 벽에서 조금 더 멀리 두세요. TV 화면 가장자리가 잘리면 TV 화면 크기 설정을 화면 맞춤으로 바꿔요.

    누나윷은 진짜 윷으로 던져. 화면은 판이랑 점수만. 이게 제일 시끄럽고 재밌어.

    동생…말은 폰으로 옮겨.

    1. 팀 이름을 눌러 바꾸고(기본 문가네·남가네·김가네), 2팀·3팀·4팀을 골라요.
    2. 진짜 윷을 던지고, 나온 만큼 말을 끌어서 칸에 놓아요. 판이 도·개·걸·윷·모를 알아서 표시해 줘요.
    3. 상대 말이 있는 칸에 놓으면 잡기, 우리 편 말이 있으면 업기, 한 칸 뒤로 놓으면 빽도예요.
    4. 판을 다 돈 말은 골인 칸으로 끌어다 놓아요. 네 개가 먼저 들어온 팀이 이겨요.
    5. 윷이 없으면 위의 윷 던지기 화면을 켜고 화면 속 윷을 던져요.
    6. 잘못 놓았으면 되돌리기. 판은 자동으로 저장돼서 닫았다 열어도 이어져요. 누가 많이 잡았는지는 기록판에서.
    7. 👏🔥😱🤣 응원 버튼을 누르면 TV 화면에 이모지가 터져요.

    게임 화면이 열려 있는 동안은 휴대폰 화면이 꺼지지 않게 해 둬요(지원하는 브라우저에서). 그래도 꺼지면 휴대폰의 화면 자동 꺼짐 시간을 늘려 주세요.
